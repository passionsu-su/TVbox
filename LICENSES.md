# Licensing and redistribution policy

This repository initially catalogs links to third-party repositories. Listing a repository does not grant permission to copy, redistribute, modify, or commercially use its contents.

## Policy

1. The default `redistribution` value is `index-only`.
2. Before mirroring a file, verify the upstream license and that it covers the file and any included third-party assets.
3. If a repository has no clear license, treat its contents as all rights reserved and link to the original only.
4. When redistribution is permitted, preserve required copyright notices, license text, attribution, and source links.
5. Do not automatically copy executable scripts, JAR/APK binaries, copyrighted media, or credentials.
6. Flag broken, unsafe, or unauthorized entries when discovered.

This file is a project policy, not legal advice.
